# 👁️ EyeSpeak - تواصل بعينيك

تطبيق iOS للتواصل عبر تتبع العين للأشخاص ذوي الإعاقة الحركية الكاملة وغير القادرين على الكلام.

---

## 🚀 خطوات التثبيت

### المتطلبات
- Flutter 3.x+
- Xcode 15+
- iPhone مع Face ID أو TrueDepth Camera (iPhone X أو أحدث)
- iOS 16+

### 1. تثبيت المتطلبات
```bash
cd eye_speak
flutter pub get
```

### 2. تشغيل على جهاز
```bash
flutter run --release
```

> ⚠️ **مهم**: تتبع العين يعمل فقط على جهاز حقيقي، لا يعمل على المحاكي.

## 📱 مميزات التطبيق

### التواصل
- ✅ لوحة حروف دائرية - عربي وإنجليزي
- ✅ تأكيد الحرف: النظر 3 ثواني ثم رمشة قوية
- ✅ نطق الجملة بصوت طبيعي (Text-to-Speech)
- ✅ اقتراحات كلمات ذكية (AI + قاموس)
- ✅ جمل سريعة جاهزة
- ✅ حذف ومسح النص

### تتبع العين
- ✅ Google ML Kit Face Detection
- ✅ قياس EAR (Eye Aspect Ratio) لكل عين
- ✅ اكتشاف الرمشة العادية والقوية
- ✅ قياس معدل الرمشات في الدقيقة
- ✅ اكتشاف التوتر (رمش كثير > 25/دقيقة)
- ✅ اكتشاف التعب (رمش قليل < 8/دقيقة)

### الطوارئ
- ✅ زر طوارئ واضح
- ✅ صوت تنبيه قوي
- ✅ إرسال SMS لجهات الطوارئ
- ✅ إشعار محلي
- ✅ رسالة طوارئ قابلة للتخصيص

### إعدادات المشرف
- ✅ رمز PIN للدخول
- ✅ ضبط مدة النظرة (1-5 ثواني)
- ✅ ضبط حساسية الرمشة
- ✅ تغيير حجم الخط (14-32px)
- ✅ إدارة جهات الطوارئ
- ✅ تفعيل/إيقاف الاقتراحات

## 🔑 طريقة الاستخدام

1. **فتح التطبيق** → شاشة البداية ثم الشاشة الرئيسية
2. **تشغيل التتبع** → اضغط "👁️ تتبع" 
3. **الكتابة** → انظر إلى حرف 3 ثواني
4. **التأكيد** → رمشة قوية (إغلاق العين > 300ms)
5. **النطق** → اضغط "🔊 تكلم" أو رمشة قوية بعد الجملة
6. **الطوارئ** → اضغط "🚨 طوارئ" مطولاً
